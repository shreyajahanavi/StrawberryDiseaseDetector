Academic Mini Project Overview

Explainable & Environment-Aware Strawberry Disease Detection

An Enhanced ResNet9-SE Framework integrating Squeeze-and-Excitation channel attention, Gradient-weighted Class Activation Mapping (Grad-CAM), and microclimate disease risk modelling.

Section 01

Problem Statement & Objective

The Agricultural Challenge

Strawberry crops (Fragaria × ananassa) are highly vulnerable to foliar fungal and bacterial pathogens such as Leaf Scorch (Diplocarpon earlianum), Powdery Mildew (Podosphaera aphanis), and Angular Leaf Spot (Xanthomonas fragariae). Left unchecked, these pathogens ravage photosynthesizing leaf area, defoliate crowns, and trigger severe yield losses exceeding 40–65%.

Current farming workflows rely heavily on subjective visual scouting and broad-spectrum chemical sprays applied prophylactically. This increases input costs, fosters chemical pathogen resistance, and contaminates agricultural runoff.

Our Solution & Research Objectives

This research introduces an integrated digital diagnostic platform engineered to:

  • Deploy an Enhanced ResNet9-SE: A high-throughput, low-parameter deep residual neural network optimized for fast inference on resource-constrained agricultural edge devices.
  • Incorporate SE Attention: Squeeze-and-Excitation blocks dynamically recalibrate channel feature weights, sharpening model sensitivity to fine-grained foliar lesions.
  • Deliver Visual Explainability: Grad-CAM heatmaps generate visual accountability, assuring agronomists and farmers of why a prediction was made.
  • Correlate Environmental Telemetry: Microclimate temperature and humidity sensors (via ESP32 + DHT22) inform disease risk assessment before irreversible sporulation takes hold.
Section 02

Enhanced ResNet9-SE Architecture

Standard deep architectures like ResNet-50 and DenseNet-121 contain tens of millions of parameters, requiring heavy GPU hardware that is impractical for edge IoT deployment in rural field conditions. Our enhanced framework builds upon a compact 9-layer residual architecture enhanced with channel-wise Squeeze-and-Excitation (SE) attention blocks.

Input Stage 3 × 224 × 224 RGB Leaf
→
Prep Block Conv 3 → 64, BN, ReLU
→
Stage 1 + SE Block Conv 128 + Res(128) • SE Attention
→
Stage 2 Conv 128 → 256, MaxPool
→
Stage 3 + SE Block Conv 512 + Res(512) • SE Attention
→
Classifier Head AdaptivePool • Linear(512 → 4)

Squeeze-and-Excitation (SE) Attention Mechanism

The SE block models non-linear cross-channel relationships through two consecutive operations:

1. Squeeze (Spatial Global Average Pooling):

Aggregates spatial dimensions \(H \times W\) into a channel descriptor vector \(z \in \mathbb{R}^C\) via:

z_c = (1 / (H × W)) ∑ ∑ u_c(i, j)
2. Excitation (Adaptive Channel Recalibration):

Captures channel-wise dependencies using two fully connected layers around a reduction ratio \(r=16\):

s = σ(W_2 • δ(W_1 • z))

The resulting activation vector \(s\) rescales the original feature maps, enabling the network to selectively emphasize necrotic disease channels over plain leaf background.

Section 04

Explainable AI (XAI) via Grad-CAM

Black-box deep neural networks frequently fail to earn farmer trust because the user cannot verify whether a classification was made based on actual pathogen symptoms or extraneous background artifacts (such as soil, mulch, or water drops).

1

Forward Pass

Leaf image passes through ResNet9-SE to generate class prediction logits.

2

Gradient Computation

Backpropagates class score gradients back to the Stage 3 residual convolution layer.

3

Global Pooling Weights

Computes alpha neuron importance weights for each of the 512 feature maps.

4

Heatmap Generation

Applies ReLU to retain positively contributing features and upsamples to 224×224.
