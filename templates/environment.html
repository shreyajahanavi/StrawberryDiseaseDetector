ESP32 + DHT22 IoT Ingestion Architecture

To stream live field weather data into this dashboard, configure an ESP32 microcontroller with a DHT22 sensor to transmit HTTP POST requests over Wi-Fi.

ESP32 Arduino C++ Payload Structure HTTP POST 
// HTTP POST to /api/environment/sensor-data
HTTPClient http;
http.begin("http://<SERVER_IP>:5000/api/environment/sensor-data");
http.addHeader("Content-Type", "application/json");

String payload = "{\"temperature\": " + String(dht.readTemperature()) + 
                 ", \"humidity\": " + String(dht.readHumidity()) + 
                 ", \"device_id\": \"ESP32_FIELD_NODE_01\"}";

int httpCode = http.POST(payload);
http.end();
